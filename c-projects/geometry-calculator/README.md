# Geometry & Measurement Calculator

A menu-driven C program that calculates the area of a circle, the area of a square, and the perimeter of a kite, each handled by its own function.

## Why I built it
This project was written to practice modular function design (separating logic into reusable functions rather than one large block of code) and building a menu-driven program flow using loops and switch-case logic.

## What it does
- Presents a menu of geometry calculations
- Routes user choice to the correct function using a switch statement
- Loops until the user chooses to quit

## How to run
```bash
gcc geometry_calculator.c -o geometry_calculator -lm
./geometry_calculator
```

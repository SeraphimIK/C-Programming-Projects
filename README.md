# C Programming Projects

A set of C projects built to practice core programming fundamentals: input validation, modular functions, array-based data handling, custom search algorithms, structs/unions, and CSV file parsing.

## Projects

- Student Average Calculator (./student-average-calculator): Validates and averages a set of student grades entered by the user.
- Geometry and Measurement Calculator (./geometry-calculator): Menu-driven program calculating area of a circle, area of a square, and perimeter of a kite.
- Minnesota Earthquake Records Lookup Tool (./mn-earthquake-lookup): Array-based dataset of historical MN earthquakes with a custom search function and damage cost estimation.
- Earthquake Damage Cost App, CSV File Handling (./earthquake-damage-cost-csv-app): Parses real USGS earthquake CSV data, handling messy fields, and reports damage cost statistics.
- Student-Course-Schedule Management System (./student-course-schedule-system): Structs and a union model student, course, and schedule records, joined into a transcript report.
